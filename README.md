# Acoustic Consultant Simulator v8.5

## Changes
- Clicking the top-left waveform logo or **Acoustic Simulator** brand now returns to the opening main screen.
- Added subtle professional motion to **Build your career. Make the right call.**
- The headline gently settles into place, while the second line has a slow restrained colour movement and fine accent line.
- Motion automatically switches off when the device/browser uses **Reduce Motion**.
- Retains the complete v8.4 career, achievement, scoring and PWA functionality.
- Cache updated to `acs-v8-5`.

## Publish to GitHub
Replace all files in the repository root with the files in this pack, then run:

```bash
git add .
git commit -m "Improve landing navigation and headline motion"
git push origin main
```

If the installed PWA still shows the old build, close/reopen it or remove/reinstall it after GitHub Pages has finished deploying.
