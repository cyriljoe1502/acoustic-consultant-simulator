# Acoustic Consultant Simulator

A browser-based training game containing fictional noise,
vibration, monitoring and acoustic consultancy scenarios.

## Features

- Multiple-choice acoustic consultancy scenarios
- Graduate and consultant difficulty levels
- Score, XP, accuracy and streak tracking
- Career progression system
- Persistent progress using browser local storage
- Responsive design for desktop and mobile
- No installation or server required

## Running the game locally

Open `index.html` in a web browser.

No Node.js, npm, database or administrator permission is required.

## Project structure

- `index.html` contains the application interface.
- `style.css` contains the visual styling.
- `questions.js` contains the question database.
- `game.js` contains the game logic.
