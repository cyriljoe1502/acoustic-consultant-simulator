# Acoustic Consultant Simulator V7

A static browser-based acoustic consultancy training game.

## Features
- Career map and XP progression
- Graduate, consultant and senior scenarios
- Achievements
- Local profile and local leaderboard
- Persistent browser storage
- Responsive layout
- No Node.js or server required

## Run locally
Open `index.html` in a browser.

## Publish
Push all files to the root of a GitHub repository, then enable GitHub Pages from `main` / root.

## Important
The scenarios and criteria are fictional/illustrative. Do not treat the game as professional advice or as a substitute for project-specific standards, guidance, consent conditions or competent professional judgement.
